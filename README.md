# B站预刷新

一个为 B站首页「换一换」提供后台预加载、自定义快捷键和状态提示的单文件 Tampermonkey 脚本。

**[下载并安装 bilibili-feed-preload.user.js](https://github.com/Tnomlav/bilibili-feed-preload/releases/latest/download/bilibili-feed-preload.user.js)**

## 作用

B站首页自带的「换一换」通常只会替换前几张卡片。这个脚本会在当前页面中隐藏加载一份完整的下一页 B站首页；预载完成后，「换一换」按钮会变成蓝色。点击后会直接显示已经加载好的页面，并马上准备再下一页。

预载页面保持完整运行状态，因此切换后尚未加载的卡片仍会继续通过 B站自身的懒加载和无限滚动出现，不会变成白屏。

## 特点

- 不额外打开浏览器标签页。
- 默认在不输入文字时单击 `R` 触发，也可在设置面板中改为任意单键或组合键。
- 输入框、文本域、下拉框、可编辑区域和输入法组合输入期间不会识别快捷键。
- 预载完成后「换一换」按钮显示蓝色高亮。
- 切换后推荐卡片继续加载。
- 连续点击会合并处理，不会重复刷新。
- 预载尚未完成时点击，会短时间等待后自动整页刷新一次，避免卡死。
- 使用 `about:srcdoc` 隐藏预载页和 `@noframes`，不会让其它 B站油猴脚本在 iframe 中重复运行。
- 会同步页面净化大师的 CSS，保留现有首页净化效果。

## 设置

打开 Tampermonkey 的脚本菜单，在「B站预刷新」的菜单命令中可直接设置：

- 点击快捷键命令可启用或停用自定义快捷键。
- 点击「更改快捷键」后，在页面按下新的单键或组合键完成录制。
- 恢复默认快捷键 `R`。
- 查看当前预载状态。

## 安装

1. 安装 Tampermonkey。
2. 点击上方“下载并安装”链接。
3. 在 Tampermonkey 安装页确认安装。
4. 打开或刷新 `https://www.bilibili.com/`。

## 使用状态

- 按钮灰色或半透明：下一页正在预载。
- 按钮蓝色高亮：下一页已经准备好，可以点击换一换。
- 按钮红色：预载失败，脚本会在短暂提示后执行一次整页刷新保底。

## 键盘快捷键

- 默认键：`R`
- 只在没有按下 `Ctrl`、`Alt`、`Shift` 或 `Meta` 时响应默认快捷键。
- 在输入框、文本域、下拉框、可编辑区域或输入法组合输入期间不会触发。
- 可以在设置面板中录制 `Ctrl+...`、`Alt+...` 或功能键等新组合。

## 适用范围

- 仅支持 B站桌面首页：`https://www.bilibili.com/`
- 不支持视频页、直播页、搜索页。
- 建议只启用本单文件版，不要同时启用其它会接管「换一换」的脚本。
